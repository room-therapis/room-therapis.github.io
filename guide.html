2入室・ご利用

スタッフは常駐していません。ご予約の時間になりましたら、地下のルームセラピスへ直接お越しください。

  1. お部屋に入る入口は開いています。入室後は防犯のため、お部屋の内鍵をおかけください。
  2. 備品を受け取るご予約時に購入した消耗品とレンタルタオルは、地下中央のパントリーにご用意しています。
  3. 荷物をしまう入口すぐの鍵付きロッカーのうち、お部屋と同じ番号のものをお使いください。
  4. プレートを切り替えるドア横のサインプレートを「空室」から「使用中」にしてください。
  5. 施術を行う電動ベッドや施術機器は自由にお使いいただけます。

オイルをご使用の場合

  • 備え付けのヒートマット・綿シーツの上には、必ずタオルや防水シーツを敷いてください。お持ちでない場合は、ベッド用ペーパーシーツ（60円）またはレンタル大判タオルケット（シーツサイズ・300円）をご利用ください。
  • ネイル・フェイシャル・足つぼは、テーブル用防水ペーパーシート（50円）などを敷いて施術してください。
  • ブランケットにはオイルを付けないでください。
  • オイルのボトルを床に置くときは、備え付けのトレイをご使用ください。

3退室

セルフクリーニング制です。次の方が気持ちよく使えるよう、以下の手順で片付けをお願いします。清掃道具・消毒液・洗濯済みシーツは中央パントリーにあります。

設備を戻す

  1. 電動ベッドをいちばん低い位置に戻す
  2. ヒートマットの電源を切る
  3. タイマーをリセットする
  4. ホットボックス下段の水を捨てる

清掃する

  1. 床全体のゴミを掃除機などで取る
  2. 顔枕・足枕・テーブル・鏡・タイマー・ホットボックス・オイルトレイを消毒液で拭く
  3. シーツを汚した場合は洗濯かごに入れ、洗濯済みのシーツを敷く
  4. タオルをレンタルした場合は、オイルを使ったものとそうでないものを分けて「済タオル入れ」へ返却する
  5. ゴミはパントリーのゴミ箱へ。室内のゴミ箱を使った場合は袋ごと捨て、新しい袋をセットする

お帰りの前に

  1. 室内の電気をすべて消す
  2. サインプレートを「空室」に戻す
  3. ロッカーの鍵を元の差した状態に戻す（紛失時は2,000円）
  4. 消耗品の追加購入・レンタル料・延長料金を精算する
